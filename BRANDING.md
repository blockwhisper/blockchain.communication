# blockwhisper — branding

<p align="center"><img src="logos/blockwhisper.png" width="320" alt="blockwhisper"></p>

This is blockwhisper's official branding. The source is `logos/blockwhisper.svg`: everything else is
derived from it, so change the SVG first and regenerate the rest.

## The mark

A speech bubble holding three linked blocks, with a whisper rising from the last one and a ring of
nodes around it. **A message carried by a chain, readable only by its parties, verifiable by anyone.**

| File | Use |
|---|---|
| [`logos/blockwhisper.svg`](logos/blockwhisper.svg) | **source**: the full logo, mark + wordmark + tagline (1200 × 1200) |
| [`logos/blockwhisper.png`](logos/blockwhisper.png) | the full logo as a PNG, 1200 × 1200 |
| [`logos/blockwhisper-mark.svg`](logos/blockwhisper-mark.svg) | the mark alone, without wordmark: avatars, favicons, anything under ~200 px |
| [`logos/blockwhisper-mark.png`](logos/blockwhisper-mark.png) | the mark as a PNG, 1024 × 1024. **The GitHub org avatar** |

Use the mark on its own at small sizes, where the wordmark can't be read. Keep the dark field behind
the mark, and don't recolour, stretch or rearrange it.

## Colour

| Role | Hex |
|---|---|
| Field (background) | `#090d16` |
| Whisper cyan (bubble, blocks, nodes) | `#00e1ff` |
| Signature violet (centre block, whisper) | `#8f5cff` |
| Wordmark | `#ecf5ff` |
| Tagline | `#677e99` |
| Rings | `#192b41` |
| Node lines | `#304b69` |

## Type

- **Wordmark:** `BLOCKWHISPER`, DejaVu Sans Bold, all capitals, letter-spacing 2.
- **Tagline:** `DECENTRALIZED • PRIVATE • VERIFIED`, DejaVu Sans Bold, letter-spacing 3, in the tagline colour.

DejaVu is free (Bitstream Vera licence), so the logo builds offline from the SVG alone.

## Name

Write the name as **blockwhisper** in text, all lower case, one word, and as **BLOCKWHISPER** only in
the wordmark. The concept it continues is `blockchain.communication`, set in code style.
